# EXIT PRO Terminal – 

Modern Solana token dashboard with Jupiter integrated swap, Birdeye chart embed, Solscan tx history, dark glassmorphism UI.

## Features
- Premium dark theme with blur effects
- 3-column responsive layout
- Live Jupiter Terminal for swaps
- Birdeye TV widget for charts
- Token stats & CA display

## Quick Deploy
1. Clone or download this repo
2. Open `index.html` locally or deploy to Netlify/Filebase
- Netlify: Connect repo → Build command empty, Publish dir `/`
- Filebase: Upload folder to IPFS bucket → Create Site with CID
